# 本机 CLI 品牌图标

来源：[Lobe Icons](https://github.com/lobehub/lobe-icons)，`packages/static-svg/icons/`，2026-10-26 获取。使用 claudecode-color、codex-color、cursor、geminicli-color、kimi-color SVG，原文件保留，附 MIT LICENSE。品牌名称及标志归各品牌所有。

资源随应用本地打包，不在运行时请求外网。统一白色底板使包含黑色笔画的品牌图标在深浅主题均可辨认；图标作为装饰，条目名称提供可访问名称。仅替换现有五类 CLI 的展示图标，不改变支持范围或扫描行为。
