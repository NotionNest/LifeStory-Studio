# 日记、资料库与检索

关联 REQ-01/02/12/14、TASK-07。此页是当前行为；详细存储、迁移及删除保护见 [资料库数据契约](LIBRARY_IMPLEMENTATION.md)，实际验证与未验收范围见 [当前版本验收](../VERIFICATION.md)。聊天独立于日记，创建与补充流程见 [聊天](CHAT.md)。

## 记录与保存

- 同一天可创建多篇独立日记；标题和标签可选，无标题在列表显示正文摘要，不写入标题。新建日期按当前系统时区默认为今天，用户可修改；记录日期固定归档，跨时区不自动移动，创建/修改时间单独保留。日期暂时清空不阻止正文保存，列表使用最后有效归档日期。
- 本地单一自动保存，不显示常驻保存按钮；停止输入 800ms 或持续输入最多 2 秒发起保存，⌘S/Ctrl+S 可立即提交。只有实际提交回执成功才显示已保存；冲突不自动覆盖，暂忙退避重试，权限、空间等失败明确反馈。
- 切换或退出时等待组合输入结束、停止接受新编辑并追平最新内容；目标加载期间保护旧编辑。失败或取消保留内容并恢复编辑，用户可重试、主动另存或明确放弃，不能把导出当成资料库保存成功。
- 正常重开读取已保存内容；旧版遗留恢复草稿较新时可预览并由用户选择恢复或丢弃。只承诺恢复已落盘内容，恢复成功前不清除唯一可恢复副本。
- 标签由用户手动管理，不自动由 AI 分类。编辑页支持搜索、创建、多选、当前日记及全部标签、使用数量；单篇最多 50 个。重命名、合并及全局删除尚未确定。

## 首页、筛选与搜索

默认全宽日记列表，可切换月历；点击记录进入独立详情。列表按记录日期、创建时间倒序及稳定 ID 排序，分页每次 100 条。月历周一开始、显示相邻月日期，每日预览前三篇，日期弹层可分页查看全部匹配项；点击日期不自动创建，显式新建才预填日期。列表与月历共享条件，返回首页恢复视图、月份、筛选、分页、滚动和焦点；筛选变化重置分页，过期查询结果不能覆盖当前条件。

首页使用日期和标签弹层，不展示图片筛选入口；底层查询保留图片条件。标签支持搜索、多选、全部/任一。记录日期支持是、早于、晚于、不晚于、不早于、介于、相对于今天；早于/晚于不含边界，不晚于/不早于及区间含边界，反向区间提示错误，未完成输入不覆盖已生效条件。自然周从周一开始，月末及闰年按目标月末收敛；动态条件在本地午夜、窗口聚焦或重新可见时更新，固定记录日期不因时区改变。日记不新增开始/结束业务字段；通用日期组件的完整能力和配置见 [日期组件文档](../../src/components/date-filter/README.md)。

全局命令菜单通过 ⌘K/Ctrl+K 搜索当前日记标题/正文和聊天消息，未输入时提供新建日记、新建聊天和打开设置；不检索历史、回收站、图片文字或独立 Vlog。输入最长 200 字，字面匹配，不把 `%`、`_` 当通配符；日记与聊天分别分页、失败重试并忽略旧响应。聊天每条命中消息一项，打开时定位并高亮；标题单独命中可打开会话。执行跨页操作仍须保存与离开保护；聊天附加日记保留独立选材搜索。

`library_calendar` 在单次只读事务按可见日期范围及筛选返回每日总数和前三篇，范围含首尾且最多 42 天；拒绝无效日期、逆序、非零 offset 或同时指定 month。日期弹层与已选日期范围取交集，不更改全局筛选；当天所有结果继续使用 `library_query` 分页。

## 历史与删除

通常重新进入编辑时固定上轮已有内容；普通写作自动保存不为每次输入生成历史。移除当前图片关系前保留必要历史，保护撤销和找回；空白或未变内容不新增历史。普通历史保留 90 天，当前、重要及被引用版本受保护；恢复创建新当前版本并保留恢复前内容与既有引用。

历史为独立页面，进入前追平保存；支持列表/分页、只读预览、重要标记和恢复确认。原编辑会话跨页面保留并冻结，返回恢复现场；恢复后使用新会话。只读加载可离开，写入或恢复结果不确定时阻止离开，允许同请求重试或权威重读，不盲目覆盖。

删除进入回收站，记录删除时间、预计清理时间，30 天后应用启动或运行时清理；可恢复或经二次确认提前彻底删除。删除前展示引用影响。彻底删除清除应用管理的原文、历史及引用摘录，独立创作内容保留但来源标为失效；不承诺清除外部导出、备份或磁盘取证痕迹。受影响的未来风格偏好处理仍待细化。

## 正文图片

文件选择、拖入、粘贴均直接插入正文，支持多张、逐张反馈与手动重试失败项；不先进入附件区，不替换选中文字，光标无效时追加。图片随正文就地移动/移除；删除可撤销，自动保存不清空撤销栈。历史可复制单图粘回，不设独立图片回收或 30 天恢复。

导入按字节签名验证静态 PNG/JPEG/WebP；动画 PNG/WebP、GIF、HEIC、SVG、TIFF 等明确拒绝，不自动转码或压缩。单张上限 25 MiB、4,000 万像素、单边 16,384，解码预算 256 MiB（不是进程内存上限）；有界读取并串行验证。保留原始字节及元数据，预览按 EXIF 方向生成、只缩小且去元数据；不承诺专业色彩校准。独立合成验证工具见 [图片验证](../../tools/image-validation/README.md)。

原图由当前正文、历史、消息、恢复草稿和其他记录的有效引用保护；无引用才清理，文件清理失败保留可重试状态。旧附件区及文字引用按迁移规则转为正文，旧回收图片保留为可达历史；迁移备份期限待决定。聊天图片仅本机保存，不默认发送给 AI。
