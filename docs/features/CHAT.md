# 聊天与日记整理

关联 REQ-11/13；整合已确认行为，路由与会话生命周期以 [页面架构](../architecture/FRONTEND_NAVIGATION.md) 为准。

## 聊天与资料范围

聊天与正式日记独立：进入空白聊天不创建记录或调用模型，首次发送才创建会话和消息；支持重命名、搜索、删除与恢复。日记列表不混入聊天或待采用预览。已有日记可打开右侧聊天面板，与全页聊天共享会话；关闭面板不丢草稿。普通聊天不读取日记；只有用户主动附加资料才固定选定版本和接入目标，不授权遍历整库或默认发送图片。默认轻回应、少量追问，需要时一次问一个问题；用户主动要求才整理。

## 创建或补充日记

用户主动“保存为日记”后，基于当前会话已发送文字及明确附加的资料生成可编辑预览；未发送输入不纳入。预览可修改标题、日期和正文、重新生成或返回；只有明确创建且成功后才产生普通日记，生成或失败不自动入库。创建幂等；再次采用已有聊天内容需明确更新关联日记或另建，不静默合并。

从日记聊天补充时，默认预览新增段落及文末位置，用户可修改后明确加入；记录已采用消息范围，避免重复插入。用户明确选择重新整理全文时先展示前后内容并保留图片与版本；预览绑定目标版本，目标被修改时禁止盲目覆盖并保留建议，目标删除时禁止采用并标记来源失效。成功采用走正常保存链路，支持撤销和历史。缺失事实不虚构。

## 模型与强度

- 统一搜索已启用来源的模型，展示来源；同名模型按配置分别列出，选择同时确定来源和模型。各来源独立加载、报错和重试，已保存自定义或当前模型继续可选。
- 使用已保存服务；按当前 CLI 实时目录/服务模型目录展示模型，CLI 强度只展示该模型报告的能力，切模型重置其强度选择。不编造 API 推理能力，未实现协议不显示强度控件。
- 默认保留服务配置；用户显式覆盖随发送/生成预览传递，模型/强度草稿按聊天保留。目录异步读取不阻塞导航，拒绝迟到结果，失败可重新读取，不自动换模型。
- 运行时覆盖只有模型/强度，不允许修改端点、凭据、CLI 路径或预算；Rust 再验证并解析 CLI 能力。
- 每次任务保存最终有效配置快照，后续覆盖更新会话当前选择，旧任务/消息与全局配置保持不变。复用现有快照列，无迁移。
- 同请求标识但选择不同必须冲突，重试相同请求复用原快照；运行中禁用配置切换，既有取消/隔离/预览采用保护保留。
- 兼容旧客户端未传选择的语义及历史请求序列化，缺省字段不改变旧请求哈希。

验收覆盖串联选择/目录能力/错误重试/迟到结果、草稿切换、发送与预览携带覆盖、快照不回写默认、幂等冲突、非法值拒绝。真实模型与视觉由用户验证，不代发付费请求。

按用户最新要求，输入区只保留单一模型入口，摘要同时展示模型、来源与有效强度。推理强度移到模型搜索浮层底部，选模型不关闭浮层，立即联动对应能力/默认值，可继续调整强度；点击“完成”、外部或 Escape 关闭，选择即时生效，完成按钮仅用于关闭而非保存。无强度能力的来源不显示该控件。保留不回写全局默认与后续任务生效规则。

## 答复信息

- 用户/助手角色名称仅保留给辅助技术，不在消息上方重复展示；消息依靠位置与气泡区分。
- 仅助手消息展示时间与复制，己方消息不显示这些附属操作（用户后续视觉反馈修订）。助手已保存消息展示本地时区发送时间，悬停显示完整日期时间；从 SQLite 原始时间读取，不补造历史信息。
- 消息复制仅复制该条正文，成功有图标反馈，失败可重试；不附带摘要、时间或其他消息。
- 生成中显示实时任务用时；完成后保留该任务从准备创建至完成落库的总用时，不标成模型内部思考时长。历史消息只有能关联任务时显示用时。
- Codex 通过 turn/start summary=auto 请求公开推理摘要；摘要流在正文前独立展示，生成时展开，完成后默认折叠。模型没有返回摘要时不生成虚假内容；旧回复不回填摘要。
- 只接收当前 thread/turn 下已确认 reasoning 项目的 summaryTextDelta 与完成 summary，完成数据为准；不采集 textDelta 或 content 中的原始推理。分段/项目/总长度限制保留。
- 摘要单独保存到 ai_tasks，重开可查看；不会进入聊天历史提示词、正式答复正文或日记生成输入。来源删除沿用失效规则并清空摘要；取消/完成后的迟到摘要不写入。
- 摘要当前接入 Codex，API 服务沿用既有正文流；不据此宣称所有提供商已实现推理流。

## 发送队列

- 后台生成不锁住消息输入；发送按钮仍可提交文本到当前聊天待发送队列，停止按钮独立保留。
- 同聊天仍仅运行一个模型任务。当前任务成功后按先后顺序发送，每条在出队时使用完整已保存历史，绝不并发穿插。
- 排队时固定聊天、请求标识、来源 ID、模型/强度、日期/时区；未投递正文可按用户要求原位修改；重试复用同一标识及参数，后端继续校验服务/资料/幂等。
- 生成失败、停止、上次中断或出队失败时暂停自动发送，由用户明确继续；结果待保存时必须先处理保存。
- 显示当前聊天待发送内容与数量，可修改或移除未处理条目；切换聊天不丢队列，也不把内容发到其他聊天。隐藏页面/预览时不启动新的队列任务，返回当前聊天继续处理。
- 队列与现有未发送草稿同属本次应用会话，退出前计入未保存提醒；不将尚未投递的内容冒充已保存消息，不新增后台/重启自动发送。
- 保留现有图片添加、模型选择、日记预览/采用及取消保护，不扩展协议或权限。

验证重点：顺序/仅成功后出队、输入草稿不被队列发送清空、停止与失败暂停、同请求重试、切换/隐藏隔离、未发送提醒、移除与中文输入法边界。

用户反馈缺少修改入口，已在每条待发送消息旁增加铅笔按钮，原位多行编辑，支持保存/取消及 Escape 取消，空白内容不能保存；删除继续保留。编辑期间暂停该聊天的自动队列调度，避免上一条完成时把编辑中的旧内容发出。保存后保持原有顺序与来源/模型参数，取消恢复原正文；主输入框草稿不变，切换聊天后编辑内容仍保留。提交中的条目仍受 busy 防重保护。

失败条目修改后继续保持暂停，不自动重发；继续发送复用原请求标识，让后端对已受理但回执不确定的旧请求拒绝参数冲突，避免换新标识重复发送。未新增存储/协议/依赖，队列仍沿用现有会话生命周期。


## 长聊天与连续滚动

首开读取尾部 100 条，数据库以 sequence/ID 游标按需前后读取、每次最多 100 条，消息驻留最多 300 条，虚拟列表仅挂载可见范围；这些不是聊天总容量限制。增量按 ID/sequence 去重，保留元数据、任务和来源；旧会话或较早请求的迟到结果不能覆盖新状态。查询失败保留当前内容并提供重试。搜索后端验证消息所属聊天并读取附近窗口；回到最新需成功读尾页。

连续分页、图片迟到、推理展开及宽度变化保持可见锚点；读历史时新消息不强制拉回，主动发送及成功回到最新才跟随，队列自动发送保留位置。离开驻留窗口的焦点消息将焦点归回聊天区域。显示分页不截断模型上下文、预览选材或已采用水位，整理日记是否可用按全历史判断。

schema 17 在会话保存 has_user_text；迁移按既有条件回填，消息插入时同事务维护，仅非空用户文字置位，助手和仅图片/空白不置位。旧库迁移保留备份与失败回滚；未来若支持逐条消息修改/删除，应同步修订派生标记。合成测量与实机限制见 [长聊天测量](../research/CHAT_LONG_HISTORY_MEASUREMENT.md) 和 [版本验收](../VERIFICATION.md)。
