# 模型与提供商设置

关联 REQ-11/13、DEC-13/18。设置分本机 CLI 与 API 提供商；用户明确选择接入目标，不因失败自动切换服务、安装或模型。已发现服务、读到目录、实际模型生成成功及权限隔离是不同状态，不能混为已验证；当前分支证据见 [验收](../VERIFICATION.md)。

## 本机 CLI

首次进入设置在后台扫描本机安装，本会话复用结果，可手动重扫；扫描局部运行，不阻塞设置分类、返回、API 分段或应用导航。遵循 PATH 当前默认独立 CLI，不执行其他应用包内部组件或自动选更新版本；扫描错误单独反馈，重扫不删除配置或丢失编辑。发现其他 CLI 不代表其聊天适配已接入，当前重点是 Codex。

展开 Codex 条目读取配置及目录，不发送消息或自动保存；目录按实际能力和分页返回，失败可重试，不能用当前模型冒充目录成功。支持跟随 CLI、选择目录模型或显式输入自定义 ID；跟随是用户主动选择，不是错误兜底。模型和推理强度来自实际能力，未报告的不虚构。新聊天首次使用时解析并固定有效配置，已有聊天和任务保留快照，不因 CLI 默认值变化悄然切换。

模型、强度和“用于新聊天”开关通过一次显式保存；新增或修改时出现保存按钮。配置修订与默认引用在同一事务中提交，失败保留旧配置和待保存输入；不影响已有聊天。统一测试可在保存前显式触发，先检查 CLI 通信，再按生成隔离能力测试模型；可取消，合成请求可能产生费用。兼容性按必要协议与隔离能力判断，不采用精确版本白名单；本机工具权限及版本证据见 [接入研究](../research/LOCAL_AI_INTEGRATION_RESEARCH.md)。

## API 提供商

可选择已有提供商预设、管理多份配置，编辑名称、地址、模型和高级协议/预算；保存、默认、停用、目录读取及连接测试由用户显式操作。模型下拉支持服务远程目录或自定义 ID；填写 HTTPS 地址和显式 Key 后可在保存前读取目录，只查询目录，不生成消息或保存凭据。当前模型不在目录时保留自定义，失败保留输入；目录返回不代表账户生成联调通过。地址、协议或 Key 变化使旧请求失效，不把已有密钥发送到新目标。

按 DEC-18，API Key 明文存应用私有配置，不随备份或导出；前端不读回已保存密钥或真实长度。输入始终隐藏，不提供明文查看；已保存状态依据本机凭据可读性显示固定假圆点和提示。显式更换，取消保留原值；仅修改名称、模型、预算等可保留旧密钥，地址、协议、提供商或下游变化必须输入新密钥。配置版本与凭据更新失败不得丢失旧值。无未保存修改且有已保存密钥时可直接测试；保存状态与测试结果分开，成功提示服务名，失败原因留在页面。

请求限制 HTTPS、禁止 URL 凭据和自动重定向，限制超时和响应大小，不自动重试或转向其他服务。设置草稿、取消、迟到响应及退出保护沿用窗口级会话；未保存修改不静默丢弃。真实服务、平台和模型的验证范围见 [当前版本验收](../VERIFICATION.md)。
