# 开发环境与实施顺序提案

编写日期：2026-10-14；更新：2026-10-15。开发环境与代码骨架已建立并完成 macOS 本机检查，详细结果见 [开发环境说明](../development/ENVIRONMENT.md)。完整业务能力、Windows 与正式发行验证按后续阶段推进。

测试执行边界于 2026-10-15 更新，遵循 [测试策略](../process/TESTING_POLICY.md)。下方 VAL 是功能/技术里程碑验收，不是每次编辑必跑清单；性能、大数据集、双平台与真实模型检查按风险和交付节点触发。

## 1. 方案确认后的开发环境建设

1. 核实并锁定兼容的 Node、Rust、Tauri、React、Vite 和编辑器版本，建立 React/TypeScript + Rust Tauri 项目与锁文件。
2. 配置有限 Tauri 命令、界面资源策略、类型检查、Rust 检查及必要开发说明。
3. 使用合成资料验证本地数据库、图片写入与重开，以及端到端保存状态。
4. 验证 Codex 握手、版本兼容、工具禁用与资料边界。先做不调用模型的协议检查，涉及模型/账户时明确目标与用量；不把日志输出到公开测试报告。
5. 验证 HTTP 适配器的流分片、取消和错误行为，再用用户配置且明确授权的模型完成实际创作验证。
6. 形成 macOS/Windows 构建与测试矩阵。Windows 环境未具备前可以推进共享工作，但必须标为尚未验证。

开发环境验收：实际桌面程序可启动；命令通信与真实保存/重开成立；检查可重复运行；双平台限制明确；测试工具不进入正式发行构建。

## 2. 功能实施顺序

| 阶段 | 成果 | 对应需求 | 验收重点 |
|---|---|---|---|
| 资料基础 | 日记编辑、版本、中文检索、图片附件、恢复基础 | REQ-01/02/12/14 | 保存/重开、引用基础、图片完整性、异常中断 |
| AI 与对话 | 两类入口、任务范围、取消、文字对话与日记整理 | REQ-03/11/13 | 兼容性、越界保护、草稿独立、失败及中断 |
| 写作与风格 | 审查、练习、原文定位、风格确认 | REQ-04/05/10 | 建议有依据，用户控制，反馈可回看 |
| 主题与 Vlog | 跨篇选题、项目、旁白、分镜和拍摄清单 | REQ-06—09 | 多对多复用、版本稳定、事实/建议区分 |
| 生活回顾与输出 | 周/月/年回顾、可读导出、完整备份与恢复 | REQ-12/15 | 范围可见、来源完整、CSV 安全、完整恢复 |
| 正式发行 | 安装、升级、签名与双平台回归 | 全部首发需求 | 真实用户链路、版本迁移、权限与发布包检查 |

每个阶段关联独立功能规格、任务和验证记录，不能仅靠页面完成判断进度。

## 3. 技术验证事项

| ID | 检查 | 通过条件 |
|---|---|---|
| VAL-01 | 长文与图片编辑 | 中文输入法、撤销、重开、原文引用正常；长文性能达到接受的阈值 |
| VAL-02 | SQLite 检索 | 中文一/二/多字符、标点、通配符和混合文本返回正确；索引与记录一致 |
| VAL-03 | DB 与图片备份 | 备份期间有编辑操作仍保持一致；损坏包不覆盖原资料；新目录恢复成功 |
| VAL-04 | Codex 资料边界 | 受支持版本握手成功；非选定资料与任意系统能力不可访问；取消与进程回收正常 |
| VAL-05 | 模型服务协议 | 兼容服务流式、超时、截断、结构结果和取消符合契约；失败不自动切换 |
| VAL-06 | 双平台凭据 | 系统存储可用，读写失败明确；无明文降级；密钥不进入前端读接口或导出 |
| VAL-07 | 发行构建 | embedded 测试服务器被排除；签名安装与升级有效；资料完整 |

未通过的验证作为对应功能的缺陷处理，不另行实施用户未要求的兜底方案。

## 4. 外部依赖

发行前需要明确并获得 macOS/Windows 签名方式、最低系统与 CPU 矩阵、Windows 实际测试环境，以及模型/本机工具支持名单。自动构建配置可随项目建立，但远程仓库、CI 服务与发布行为须依据用户授权执行。
