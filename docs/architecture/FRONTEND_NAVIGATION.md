## 路由及页面

采用锁定版本 React Router 8.5.0 的 Data Mode、createHashRouter 与 RouterProvider，沿用 Vite/Tauri，无服务器框架。Hash 内路径不需要服务器重写。生产使用 Hash 历史，集成测试使用同类 Data Router 的内存历史。

| Hash 内路径 | 页面 |
|---|---|
| /diaries | 日记列表/月历、筛选与待恢复草稿入口 |
| /diaries/:recordId | 日记详情编辑；历史对话可只读浏览 |
| /diaries/:recordId/history | 指定日记的历史与恢复 |
| /chats/new | 新聊天，访问不会创建记录或调用模型 |
| /chats/:chatId | 指定聊天消息 |
| /chats/:chatId/diary-preview/:taskId | 指定任务的日记预览与采用 |
| /settings/appearance | 外观 |
| /settings/models/cli | 本机 CLI |
| /settings/models/api | API 提供商 |
| /settings/trash/diary、/settings/trash/chat | 两类回收站 |

`/` 规范到 /diaries；设置、模型配置、回收站父级分别规范到外观、CLI、日记回收站，使用 replace。未知路径、无效参数、缺失资源明确显示错误，不静默转到其他资源。

日记详情 `?chat=new` 或 `?chat=:chatId` 表示辅助聊天，`preview=:taskId` 表示辅助聊天中的预览。完整聊天和辅助聊天复用同一会话与视图，不各自发送请求。预览必须通过已有 ai_task 接口核对 recordId 归属后才展示和允许采用。

路径参数只含资源标识；正文、搜索词、密钥与草稿不入地址。搜索命中使用 `message=:messageId`，关键词仅保存在窗口会话内。切换页面使用统一路径构造函数，页面身份从 Router 获取。

## 布局与状态归属

应用壳负责窗口标题栏、主导航、搜索、历史按钮、主题和页面出口。日记编辑/历史共用编辑会话布局；聊天消息/预览使用子路由出口；设置通过布局出口展示分类页。仅匹配页面挂载，不通过隐藏整个页面维持功能。

| 状态 | 所有者及生命周期 |
|---|---|
| 页面、资源 ID、当前预览、设置分类 | Router |
| 列表/月历筛选、月份、分页、滚动与焦点 | 日记浏览会话，窗口内保留 |
| 编辑器、标题日期标签、版本、保存控制器 | 日记编辑会话，跨该记录的编辑/历史子路由保留 |
| 聊天输入、来源、模型、队列、预览编辑、日记聊天关联 | 聊天会话，窗口内按聊天/新建上下文保留 |
| CLI/API 配置草稿与新输入 Key | 设置会话，仅内存保存 |
| 弹窗、局部展开、悬停 | 组件局部状态 |

复用现有 React Context/hooks，不增加全局状态依赖。页面视图卸载不删除上述会话。编辑页转历史页保留同一编辑器实例及撤销历史、冻结输入；返回重新挂载视图，恢复滚动/焦点。恢复版本成功后替换编辑会话并重建编辑器。

## 导航历史与业务操作

普通页面切换 push；地址规范化、首次发送成功把 /chats/new 提升为具体聊天地址使用 replace。创建日记、发送、生成、采用、恢复等写操作仍是显式业务动作，loader 仅读取，不能因后退/前进/刷新重复执行。

统一前进/后退使用 Router 历史。仅观察已提交 location.key 和导航类型计算按钮边界，不自建页面内容栈。后退后新跳转截断前进分支；取消导航不更新历史指示。窗口级快捷键为 macOS ⌘[ / ⌘]、Windows Alt+← / Alt+→，编辑控件、已处理事件和组合输入不抢占。

“返回日记”“返回编辑”“返回聊天”保留明确业务目标，不等同历史后退。设置入口携带进入前的完整地址；直接进入设置时“返回主界面”明确进入日记首页。列表返回恢复浏览现场；消息定位失败明确报错，不定位另一条消息。

## 保存、导航与退出保护

导航协调器使用一个 useBlocker 汇总日记、历史及业务写入保护。普通链接、命令菜单、辅助面板开关、前进后退都经过拦截，不能仅依赖按钮 disabled。

1. 日记离开前等待组合输入、冻结并 flush。保存失败保留重试、主动另存、继续编辑、明确放弃。进入历史必须先保存，不借放弃路径绕过。
2. 离开记录前结束编辑会话；结束失败保留页面并恢复编辑。编辑/历史往返不结束同一会话。
3. 历史读取可离开；写入、恢复结果未知时不可离开。保留请求标识、幂等重试和权威核对。
4. 图片结果未知或日记采用后重新读取失败时冻结写入，用户核对成功再恢复。
5. 聊天/API/CLI/回收站的写操作或显式连接测试期间拒绝导航；只读扫描和目录加载不阻止普通导航。
6. 聊天、预览及配置草稿在会话中保留，普通切页无需放弃；窗口退出检查所有内存草稿与待发送队列。
7. Tauri exit-requested 使用同一业务准备逻辑。useBlocker 不保护窗口关闭、硬刷新或跨源跳转；beforeunload 仅按 WebView 支持提供未完成内容提示。

运行中的 AI 任务仍由 Rust 管理。视图卸载不取消或重发；返回可见聊天后先核对任务状态再调度队列。隐藏、预览、暂停、编辑队列、失败/取消或结果未保存时不自动投递；显式继续复用原请求。

异步读取以资源 ID、请求序号/取消信号隔离，迟到结果不能覆盖新页面或另一个会话。预览读取失败保持错误与明确返回入口，不展示其他任务。

## 刷新、兼容与边界

有效 Hash 地址在刷新后重新读取已保存资源。窗口内草稿不新增磁盘持久化，刷新不承诺恢复未发送/未保存输入；新启动无 Hash 时进入日记首页。不新增 OS 外部深链、多窗口、云同步、遥测、上传、账号或数据库迁移。

历史只读对话、旧版恢复草稿、已删除来源与既有版本冲突保护继续保留。路由只负责页面身份和加载状态，不替代 Rust 的持久化和信任边界。

## 验收

真实 Router 集成验证地址、push/replace/POP、导航取消、连续请求、保存与历史、卸载后的草稿保留、预览归属、迟到结果、队列恢复及退出；组件库不增加测试。类型/生产构建与前端套件通过后，分别记录 macOS/Windows 的 Hash 地址、快捷键、关闭、中文输入法与刷新提示检查，未运行的平台不得标为通过。
