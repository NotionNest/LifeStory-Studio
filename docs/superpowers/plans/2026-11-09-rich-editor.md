# 日记富文本编辑扩展实施方案

关联 REQ-01/04/12/14。用户确认 Markdown 采用输入语法自动转换为富文本，非源码编辑。

1. 扩展编辑器格式：下划线、删除线、文字/背景颜色、清除格式、对齐、有序/任务列表、引用和缩进；使用可访问的工具栏并反馈当前状态。
2. 扩展原生正文校验，严格限定节点、属性和颜色值；确保自动保存、重开、历史恢复及图片引用不丢失。
3. 编辑器与只读历史、检索预览共享相同文档格式；文案审查需保留新增格式及图片。
4. 验证实际 Markdown 输入规则及撤销、列表嵌套、颜色、对齐、任务勾选、清除格式；覆盖真实存储保存重开、历史与审查边界。深浅主题及键盘在桌面验收。

不以源码模式或模拟数据替代真实编辑保存；不新增 Markdown 导入导出需求。
