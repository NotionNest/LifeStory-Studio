# 日记心情与系统表情面板实施方案

关联 REQ-01/02/12、TASK-16；状态：实现和合成数据验证已进行，双平台真实交互与用户验收未完成。

## 目标与边界

- 日记编辑页日期及标签附近提供心情入口，用户选择系统表情；不增加第三方表情库或自动推断心情。
- 心情作为日记属性随自动保存、重开、历史快照与恢复一起处理；不得混入正文或破坏已有记录、图片、标签及保存保护。
- 新增字段需对旧资料库和旧历史快照兼容，并覆盖更改、清除、取消、保存失败、版本冲突和恢复；具体交互与呈现为实施设计，不等同已完成或验收。
- macOS 和 Windows 均须核实是否有可靠的应用主动唤起系统表情面板方式以及输入焦点行为；不得以自建表情库或仅支持一个平台冒充已实现。

## 工作拆分

1. 核验双平台官方接口及 Tauri 主线程、焦点与权限要求，明确取消和多码点表情输入行为。
2. 设计 SQLite 迁移、记录/保存协议、恢复草稿、历史快照与恢复，并保持旧数据兼容；编写真正存储测试。
3. 在编辑页接入入口和系统面板，支持设置、修改和清除；接入当前编辑会话、失败保护与键盘/辅助技术。
4. 使用合成数据验证保存重开、旧数据迁移、历史恢复、竞态、撤销边界及双平台真实交互；按实际证据更新验收记录。
