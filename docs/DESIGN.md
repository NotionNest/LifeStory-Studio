# 设计与交互基线

本页记录现有产品的设计方向和已实施规则，供后续功能沿用；功能细则见 [日记](features/DIARY.md)、[聊天](features/CHAT.md)和[模型设置](features/MODEL_SETTINGS.md)。用户确认的方向、实现选择及尚未验收的体验分别标注；现有实现不代表所有平台和辅助技术均已验收，见 [当前版本验收](VERIFICATION.md)。

## 方向与参考

用户确认的方向是有表现力和探索感的创作工作室：深色、聚焦、少干扰，突出文字与画面；保留精简导航，列表和辅助面板按需收起，把空间留给内容。支持深色、浅色和跟随系统，默认跟随系统，主题偏好本地保存；写入失败需反馈，不能冒充已保存。

Codex 桌面软件是首要设计和交互参考，Cloudflare 控制台与 Notion 工作区为辅助参考；借鉴导航和内容组织，不自动引入这些产品的账号、工作区、终端、审批或其他业务。参考分析见 [Codex 参考](research/CODEX_UX_REFERENCE.md)，不能将用户偏好扩大为认可参考产品的所有细节。

## 工作区与视觉

- 日记、聊天、设置使用统一外壳；日记首页为全宽列表/月历和独立详情，设置为独立页面，回收站在设置内区分日记与聊天。历史为独立页面。全局导航负责切换模块，页面标题栏右侧承载当前页面操作；编辑与返回路径保留在内容区。
- 面板由用户主动开合，入口可发现且有可访问名称与展开状态；收起不丢草稿或浏览状态，焦点返回触发入口。窄窗口仍需可操作，不自动引入新折叠机制。日记可在右侧打开共享聊天，会话和草稿保留、宽度可调整并记忆。
- 内容区保持不透明；仅应用外壳、标题栏、窄导航与内容框外围使用原生 Sidebar Vibrancy / Acrylic。深浅主题共用布局，语义色统一由全局变量管理；界面采用系统字体、Lucide 图标、已有 Tailwind/shadcn 控件，不另装整套组件或字体。
- 现行实现基线：40px 标题栏、48px 窄导航、导航按钮 40px、间距 8px；编辑正文约 16px、行高 1.9、内容最大宽约 820px。用户确认的导航状态以中性透明叠层表达：浅色 hover/选中/选中后 hover 为黑色 6%/12%/16%，深色为白色 8%/14%/18%；选中图标浅色黑、深色 #F5F5F5。具体表现和跨平台效果仍需按实际界面验收，不把实现数值全部记为独立审美确认。
- macOS 标题栏使用 Overlay 并保留系统窗口按钮；空白或标题可拖动和双击缩放，交互按钮不作拖动区；Windows 使用系统窗口装饰。侧栏开合按钮无常驻底色，hover 才显示背景，并保留焦点环。
- 编辑正文不显示包围正文的蓝色焦点框，但保留文字光标和其他控件的键盘焦点反馈；聊天输入同样避免蓝色框线，不能削弱按钮焦点或输入法保护。长标题、窄窗口和内容溢出应保持操作可达。

## 文案、状态与操作

用户明确要求精简 UI 文案：控件和标签能表达时，不额外添加功能解释、教学、宣传、统计范围或无事件的常驻状态；冗余内容不转移到 Tooltip、折叠区、占位符或屏幕阅读器文本。清理文案后收拢布局，但不能缩小点击区域或删掉必要可访问名称。

保留标题、标签、对象身份和图标功能提示；保存、加载、生成、取消、复制、恢复、失败和重试等状态只报告实际事件，不重复表达。未保存离开、覆盖、彻底删除、服务不可用或实际付费测试等影响选择的信息，应在操作处简短说明。错误须可理解、可处理，并保留输入和现有保护；不得因简化界面删除保存、来源、采用或恢复边界。

标题栏少量高频操作独立显示，其余进入更多菜单；危险操作分隔并保留确认。日记详情提供聊天、重命名、新建、历史和删除；全页聊天提供保存为日记及相关操作。分享、整篇日记复制及其他模块的标题栏迁移未定义，不作为现有功能承诺。

## 通用交互与可访问性

- 纯图标操作提供可访问名称与简短 Tooltip；鼠标悬停及键盘聚焦可用，点击/Escape 关闭，弹窗内提示留在弹窗内，离开视图隐藏；禁用功能的说明仍可通过可聚焦外层查看。带清楚文字的装饰图标不重复提示。
- 全键盘路径、清晰焦点、弹窗退出及焦点归还、状态不只依靠颜色、深浅主题可读性是设计要求；组合输入期间不误触发送或破坏性快捷键。不能以局部自动化或截图宣称读屏及完整无障碍验收通过。
- 使用原生滚动并统一主题外观：12px 区域、约 6px 可见圆角滑块，透明轨道；浅色正常/hover/拖动使用黑色 18%/30%/42%，深色使用白色 16%/28%/40%，强制颜色使用系统色。保留原生键盘、拖动与位置，不增加隐藏计时或自制滚动引擎。
- 设置和聊天侧栏以整体宽度和内容淡入淡出，主区域同步变化；避免弹跳和逐项错峰。收起后隐藏内容不可交互或聚焦，关闭前焦点归还触发器；遵循系统减少动态效果。设置分类只挂载一份导航，按侧栏状态切换位置，不等待动画完成。
- 2026-11-06 用户明确：打开或切换到日记右侧聊天时不要出现横向滑入；日记侧边聊天不挂载全页聊天的历史侧栏，避免其收起挤动内容。全页聊天与设置的侧栏行为不因此改变。
- 日记右侧聊天默认 416px，通常限制 320–640px，尽量给编辑区保留 360px；空间不足时临时收窄而不覆盖记忆宽度。分隔线可通过键盘调节，缩放不更改用户偏好；读写失败反馈但不影响日记与聊天数据。
