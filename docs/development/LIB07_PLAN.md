# LIB-07 记录回收站与来源失效实施计划

关联 TASK-07、REQ-02/12/14。基线 develop 7e0d873，分支 feat/library-trash。用户已授权实施，并在验收通过后授权提交和推送；未授权 PR、合并或发布。2026-10-21 用户明确提供提前彻底删除入口，二次确认后立即执行。

目标：删除前核对引用影响，回收站内恢复或彻底删除，删除满 30×24 小时自动清理，独立稿件保留且来源失效，共享图片及失败重试受保护。

架构：复用单线程数据库队列、Immediate 事务及图片 pending_delete 清理。schema 10 为来源关系增加不含原文的失效身份。移入回收站核验 contentVersion，切断编辑会话并增加版本；恢复同样换代，拒绝旧写入。彻底删除在事务内解除来源与版本外键、删除记录及级联数据，再重试无引用物理图片清理；失败时不宣称完整清理成功。既有迁移快照和外部导出保留，界面明确告知。
