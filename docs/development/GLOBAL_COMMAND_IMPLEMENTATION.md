## 入口与行为

- 全局窄导航提供“搜索与快捷操作”，支持 ⌘K / Ctrl+K；其他模态打开时不叠加。未输入时只显示新建日记、新建聊天、打开设置，不新增最近访问或搜索历史。
- 输入后按操作、日记、聊天分组。输入最长 200 字，去除首尾空白，输入法组词结束后防抖 200ms；两类内容并行查询、独立分页和错误重试，忽略旧响应，追加结果按身份去重。
- 日记标题或现有摘要、记录日期和正文命中摘要；聊天每条消息一项，显示会话标题、角色和摘要；会话仅标题命中时显示会话结果。
- 支持上下选择、回车执行、Esc 关闭。取消恢复原焦点，执行后焦点交给详情、聊天消息/输入框或设置标题。关闭菜单清理搜索展示，不改变页面筛选。
- 移除日记首页及聊天侧栏的文字搜索框；首页保留日期、标签及图片筛选，聊天“附加日记”的选材搜索保留。
- 图标使用 Lucide，组件使用当前 radix-nova 官方 Command/Dialog，新增唯一运行依赖 cmdk 1.1.1；保留项目 Button、Tooltip、InputGroup 定制，弹窗滚动条沿用主题规范。无额外说明、统计口径和快捷键教学页脚。

## 查询接口

日记继续使用 `library_query`，使用独立空筛选加关键字查询；不读取或改写首页条件、月份、分页与位置。Command 禁用本地二次筛选，保留正文命中。

新增只读 `ai_chat_search(keyword, offset)`，返回 `{items, nextOffset}`。每项为 `{chatId, title, messageId, role, excerpt}`；标题结果的 messageId/role 为空。每页 100 项，按聊天更新时间倒序、会话 ID、消息序号倒序和消息 ID 稳定排序。有效聊天内的文本消息分别命中；没有消息命中时才返回标题命中项。沿用字面子串搜索，不把 `%`/`_` 当通配符；空查询或超过 200 字被拒绝。摘要复用现有有界纯文本截取，不返回任务内部字段；排除删除内容，不搜索图片文字。旧 `ai_chat_list` 契约不变；无数据迁移、模型调用或自动上传。

## 导航与数据保护

App 分发菜单操作，日记沿用保存/离开保护，跨页快捷操作通过 LibraryHandle.run 等待保存与轮次结束；失败保留编辑器和待执行目标，明确放弃后才继续。新建与打开日记沿用现有创建、读取和编辑接口。

聊天意图增加 chatId、可选 messageId/keyword 与 nonce，通过原有 switchChat 保留输入和待采用预览缓存。打开消息后等待加载和布局，调用已安装滚动组件的 scrollToMessage，焦点落到消息并高亮命中词；同会话再次选择仍定位。定位期间不自动拉回底部，回到底部恢复跟随；正常切换或成功发送清除定位状态。失效结果显示错误，不自动选择其他内容。
