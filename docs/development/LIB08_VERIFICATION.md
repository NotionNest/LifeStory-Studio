## 当前实现

- 应用分为日记、聊天、设置。默认服务配置好即可发送；首条消息与聊天创建原子保存。聊天拥有独立列表、搜索、重命名及回收站，不进入日记列表、搜索和日历。
- 服务配置在设置中，支持默认服务、编辑、连接测试及模型目录。更换默认只影响新聊天，既有聊天保留服务；没有自动切换或重发。
- 聊天使用官方 shadcn Radix AI Elements 的消息、滚动及输入组件，保留 Rust IPC、流式输出、取消、中文组合输入和本地保存保护。
- 生成结果是持久、可编辑的日记预览；明确创建后才成为普通日记。取消或返回聊天不会新增日记。旧整理稿迁为普通日记，保留身份、正文与来源。
- 从日记发起关联聊天，可生成新增段落或明确选择全文重新整理。预览显示修改前内容，采用时检查目标版本，保留图片和历史；支持撤销本次采用，已采用消息范围防止重复补充。
- schema 11—15 保存任务、来源版本、预览、采用凭据、服务默认值和聊天上下文。真实 SQLite 回归保护迁移、幂等、版本冲突、删除栅栏、重启与晚到结果。已采用目标被彻底清理后不能重复创建。
- 图片只在本地保存，不进入模型请求。API Key 保存在系统凭据存储，前端不读回；改变目的地需新配置与凭据。
- 15 家通用服务预设及自定义协议覆盖范围见[服务研究](LIB08_PROVIDER_RESEARCH.md)。协议实现不等于真实账户或每个模型均已联调。
