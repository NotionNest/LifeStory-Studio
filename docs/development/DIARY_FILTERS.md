## 日期条件

实现“是、早于、晚于、不晚于、不早于、介于、相对于今天”。统一在同一弹层里通过条件选择、日期输入、中文周一开始的日历完成操作。

单日期条件支持今天、明天、昨天、一周前、一周后、一个月前、一个月后、自定义日期；区间可输入两端或直接点选日历。早于/晚于不含边界，不晚于/不早于及区间含边界。反向区间就地提示，不发送无效查询；未完成的新区间不覆盖已生效条件。

相对于今天支持过去/未来/本与天/周/月/年。“本”使用自然日、周一至周日、自然月和自然年；过去为一单位之前至昨天，未来为明天至一单位之后，均不含今天。月/年偏移在月末或闰日按目标月份最后一天收敛。动态条件和日期快捷选项在本地午夜及窗口重新聚焦/恢复可见时重算，固定日期不随时区重归档。只在当前运行中保留，不新增持久化偏好。

与截图的数据差异：当前日记只有必填的“记录日期”，不增加开始/结束两个业务字段，也不显示空值条件；区间两端只是查询上下界。此为基于现有数据契约的实施选择，已向用户说明并征询，不将未收到的选择记录为用户确认。

## 通用组件与业务接入（2026-10-26）

- `DateFilterContent` 默认启用开始/结束字段、九种比较与空值条件、全部日期快捷选项、区间输入/点选和完整相对日期；不绑定日记、IPC 或数据存储。
- `capabilities` 可按字段、条件、快捷选项、相对方向与单位配置启用项；字段可重命名。关闭的能力不会通过日历交互重新产生；不符合配置的受控 value 明确报错，不静默替换。
- `resolveDateConstraint` 解析边界与空值约束；`matchesDateCondition` 对指定端点的真实日期执行匹配，包括 null 值；`useResolvedDateCondition` 提供可复用的午夜/聚焦/可见性更新与 inactive 清理。
- 日记使用薄适配层，启用记录日期及七种有意义条件，继续转成原 dateFrom/dateTo；通用空值/结束日期能力没有被删掉，也没有为展示它们改变日记数据模型。
- 组件复用现有 shadcn Calendar、Popover、NativeSelect、Input；不新增依赖、运行时插件注册表、演示路由或配置持久化。日记保存、首页状态与搜索行为保持原契约。

这一结构由用户明确要求，取代此前将日记功能裁剪等同于整体组件能力的处理；字段、空值和禁用能力都已有行为测试，而不是仅补菜单项。
