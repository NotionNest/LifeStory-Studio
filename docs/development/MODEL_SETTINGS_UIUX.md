## CLI 统一保存（2026-10-26，最新规则）

用户确认将模型、推理强度和“用于新聊天”开关合并为一次显式保存。替代此前独立“设为聊天默认”按钮，保存文案统一为“保存”，新增或有修改时出现；干净配置不显示操作栏，默认配置在条目名称旁显示“默认”。开关只是待保存选择，切换不立即写入；放弃修改恢复已保存值。

开启并保存：该配置作为新聊天默认服务；关闭并保存：仅当当前配置是默认时清除默认，不干扰其他默认服务。配置修订与默认引用变更必须在同一数据库事务提交，失败保留原配置/默认状态及前端待保存输入。继续保留配置不可变修订、任务来源与正在运行任务保护；不修改已有聊天或自动发起模型请求。现有 API 提供商设置不变。

沿用 configure/update 命令，增加仅 CLI 可用的可选 useForNewChat 参数；未传参数保留原调用语义，无新命令/权限/迁移/依赖。

Codex 兼容判断（2026-10-26）：按当前 CLI 的必要协议/隔离能力检查生成，移除精确版本白名单；发现已安装不等于已验证模型连通。展开条目读取目录采用局部状态，不锁定设置导航；生成/测试缺失能力显示具体错误，不自动换服务或升级安装。技术证据见 [本机接入调研](LOCAL_AI_INTEGRATION_RESEARCH.md)。

2026-10-27 用户要求 API 模型支持列表与自定义 ID：模型下拉始终提供自定义输入，远程目录可在配置保存前使用显式 Key 读取；原保存后才能查询的行为被替代。详情与验证见 [API 模型选择](API_MODEL_SELECTION.md)。
