## 确认的行为与边界

- 保留全局窄导航、40px 标题栏、主题和外壳磨砂；内容区保持不透明。日记隐藏无用途的侧栏展开/收起按钮，聊天和设置沿用现有结构。
- 首次进入日记为全宽列表表格，可切换月历。只在本次运行中记住视图、月份与浏览状态，不新增持久化偏好。全局“日记”入口始终回首页，离开详情执行相同保存保护。
- 列表列为日记、记录日期、标签；无标题沿用正文首段摘要，不写入标题。沿用记录日期倒序、创建时间倒序、ID 排序与每页 100 条的加载方式，不新增排序菜单、发布或状态字段。
- 列表与月历共享关键字、日期、标签及图片筛选。筛选变化重置分页与浏览位置；切换视图保留筛选。记录日期保持固定，不以当前时区重新归档。
- 月历周一开始，按自然 4—6 周显示相邻月日期；最小宽度 700px、日期格至少 144px，高度不足正常滚动，窄窗口允许水平滚动。支持月份选择、前后月和今天。
- 同一天预览前三篇，点击条目直达详情；点击日期或“还有 N 篇”打开当天列表 Popover，可分页查看全部匹配记录。弹层日期与现有日期筛选取交集，不改写全局范围；点击空白或日期不创建记录，显式新建预填日期。
- 首页保持挂载，详情返回恢复筛选、视图、月份、已加载分页、滚动位置和焦点；原条目消失时聚焦邻近条目。查询过期响应不得覆盖新条件。
- 详情沿用原编辑器、图片、历史、回收站、自动保存及错误反馈。返回前等待保存，失败保留编辑现场；明确放弃仍走已有丢弃流程。正常返回结束编辑轮次，结束失败保留详情可重试，丢弃成功不重复结束轮次。
- 启动时在首页提供待恢复内容入口，不自动打开首个恢复项。聊天关联日记使用同一详情，提供返回聊天，保留原聊天现场。
- 图标使用现有 Lucide 与统一 Tooltip；保留可访问名称与焦点。只添加必要标题、字段、查询进度、错误和操作反馈，不引入功能说明或统计页脚。

## 月历查询契约

`library_calendar` 输入 `{ query: { filters: LibraryQuery, from: YYYY-MM-DD, to: YYYY-MM-DD } }`，返回 `{ days: [{ date, count, items }], tags }`。范围含首尾、最多 42 天；拒绝非法日期、逆序范围、非零 offset 和同时指定 filters.month。全局日期条件与可见范围取交集。

复用现有搜索、标签 all/any、图片及记录有效性筛选；在同一只读事务内按天统计准确数量，并用窗口函数选出每日前三篇。返回所有可见日期，包括 count=0 的日期，不受列表每页 100 条限制。当日全部条目继续调用原 `library_query` 日期筛选和分页。无数据库迁移，无新索引或内容写入路径。
