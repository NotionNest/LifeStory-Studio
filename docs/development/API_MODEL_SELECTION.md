# API 模型目录与自定义 ID

2026-10-27，TASK-08 / REQ-11/13。用户要求模型可从预设或远程列表选择，并能切换为自定义模型 ID。本次采用所配置服务的远程目录，与自定义输入并列；未增加静态模型预设。

## 行为与边界

- 模型下拉菜单始终可见，固定包含“自定义模型 ID（在下方填写）”。选择自定义显示输入框；选择目录模型直接使用返回的模型 ID。
- 填写 HTTPS 地址与 API Key 后，无需先填模型或保存配置，即可显式读取远程目录。只 GET 模型目录，不生成消息，也不自动保存配置/凭据。
- 已保存且地址/协议未变、未输入新 Key 时，沿用原配置读取本机密钥；改过地址/协议时，必须提供新的显式 Key 才能读取，不把已保存密钥发往新目标。
- 读取目录仅按钮展示局部加载，不占用设置全局 busy；地址、协议、Key、配置变化或卸载使旧请求结果失效。模型输入不因失败丢失；当前模型不在目录时保持自定义，不替换成其他模型。
- 继续沿用协议认证、HTTPS/无 URL 凭据、禁重定向、禁自动重试、超时与响应大小限制。目录校验不要求模型 ID 或生成路由偏好；实际保存与调用仍执行完整模型/路由校验。
- Chat/Responses、Messages 与 Gemini 沿用现有对应目录解析；CLI 继续使用独立目录。目录返回不等于账户调用已验证，不自动改服务或模型。

## 实现与验收

扩展现有 ai_models IPC：已有 profileId 调用保持有效；新增 profile/key 临时查询模式，两种模式不能混用。临时 Key 只用于这次查询，不进入 SQLite、本机凭据文件、错误详情或模型请求。复用模型读取与校验，无新命令权限/依赖/数据库迁移。

前端覆盖新配置空模型直接读取、目录选择与自定义保存、读取期间其余字段可用、地址变化迟到结果丢弃、旧密钥不跨目标复用、失败保留输入。Rust 覆盖无模型可读取的目录边界、非法 URL/Key/CLI 拒绝及不修改原配置。

最终类型/生产构建、前端 AiSettings/ChatWorkspace/ChatModelControls 三文件 35 项、Rust 请求契约 3 项、Clippy lib、diff 通过。实现中一次漏括号已在编译时发现并修复。单轮设计检测无发现/忽略。主 JS 1,095.90kB，保留既有大包警告。原生命令参数变化需重启开发进程，无需打包；未操作应用、未代做视觉/真实 API Key/模型或 Windows 联调，未跑全套、未提交发布。
