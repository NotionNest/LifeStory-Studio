# 日记历史与恢复独立页面

2026-10-27 页面架构修订（TASK-09 / DEC-17）：当前页面、导航与会话生命周期以 [前端页面与导航架构](../architecture/FRONTEND_NAVIGATION.md) 为准；本文历史实现记录中的页面状态/整页隐藏方式已被统一路由取代，业务验收要求继续保留。实际验证见 STATUS.md。

2026-10-27，TASK-08 / UX-02/06/12/16，REQ-01/02/12。用户明确历史与恢复不再以弹窗打开，需为独立页面。

## 行为及验收

- 日记更多菜单“查看历史”先完成原有保存和版本核对，再进入工作区内的独立历史页面，不使用 dialog、遮罩、固定全屏层或原生模态。
- 页面保留当前/历史版本列表、分页、版本摘要、只读长文/图片预览、重要标记和恢复确认，顶部“返回编辑”回到原日记。
- 原编辑器保留挂载并冻结；返回时恢复编辑、原滚动位置并将焦点交回标题栏操作或标题。恢复成功使用新编辑会话，不沿用旧版本号继续写入。
- 历史页面不是导航阻断层：只读加载时可返回或切换模块；标记/恢复等写入期间及恢复结果未确认时阻止离开，避免悬空恢复或继续编辑覆盖。未知结果仍可同请求重试或重新读取已保存内容核对。
- 历史场景不注册日记编辑操作；侧边聊天不占历史页面宽度，聊天草稿/会话继续保留。全局导航沿用现有保存/退出流程。
- 无新存储协议、依赖或恢复规则，不能因页面迁移削减原数据保护。

## 实现与验证

当前实现：HistoryPage 位于 /diaries/:recordId/history 子路由，编辑页视图卸载，编辑器实例和保存控制器由父级日记会话保留；HistoryHandle.canLeave 由统一导航协调器动态读取。恢复成功后替换编辑会话并回到编辑路由，读取可离开、写入及未知结果不可离开。原 LibraryWorkspace 页面状态机已删除。

验证覆盖非弹窗呈现、保存失败不进入历史、返回原内容/滚动、恢复确认与新会话继续保存、正常跨页导航、只读加载不阻塞返回，以及未知恢复结果下的导航防护/幂等重试/核对恢复。实际窗口、焦点及图片/长文滚动仍由用户验证，不用 DOM 断言代替平台验收。

最终类型/生产构建与相关前端三文件 22 项通过，diff 及单轮设计检测通过（无发现/忽略）。新增跨页测试最初受已有列表 mock 状态影响，改用已存在的打开日记入口后通过，未改验收或业务规则。主 JS 1,096.64kB，既有大包警告保留。纯前端热更新；未操作应用/代做视觉、Windows 或真实资料验证，未跑 Rust/全套，未打包提交发布。
