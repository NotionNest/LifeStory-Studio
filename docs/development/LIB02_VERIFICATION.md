# LIB-02：文字记录与持久化交付

日期：2026-10-15。关联 REQ-01/02、TASK-07、LIB-02。本机验证通过，代码提交 `0d44420` 的 [macOS/Windows CI](https://github.com/NotionNest/LifeStory-Studio/actions/runs/38707797826) 已通过测试、静态检查及桌面编译。未合并 main 或发布安装包。

## 可用行为

独立创建同一天的多条文字记录，编辑结构化正文、标题和记录日期，添加/移除记录标签；手动按钮或 ⌘S/Ctrl+S 保存；列表按记录日期及创建时刻排列，可分页继续加载，关闭重开读取真实本地数据库。

保存事务同步正文版本、当前指针、标签和搜索文本。base revision 冲突明确失败；请求身份与输入匹配后可重放回执，未改内容不重复创建内容版本。当前输入比已返回的保存回执更新时继续显示未保存。正文限制为 2 MiB、深度 64、最多 50,000 节点；标题最多 240 个字符、每记录最多 50 个标签，标签最多 64 字符。正文仅接受已启用的 StarterKit 节点与标记，链接和附件节点尚未开放。

标签去首尾空白并使用 Unicode NFC 归一键；不自动合并大小写或全半角。依据经 Context7 检索 rusqlite/Tiptap/Tauri 文档；NFC crate 的 Context7 检索无准确条目，另核实 [unicode-normalization 官方文档](https://docs.rs/unicode-normalization/0.1.25/unicode_normalization/)。

## 迁移与接口

schema 1 → 2 前使用 SQLite backup 生成受管理目录内的快照，完成并同步文件后才执行编号迁移。事务失败保留旧 schema 和内容，拒绝高版本写入。迁移文件为 [002_records.sql](../../src-tauri/migrations/002_records.sql)，传输类型与 IPC 见 [api.ts](../../src/features/library/api.ts) 和 Rust commands/records；契约不再平行复制于 docs。

保存回执存于 record_save_receipts，关联内容版本与记录，清理版本或彻底删除记录时需同时清理其中的输入副本。LIB-04/07 激活保留期限与清理前必须覆盖该关联。

只开放创建、读取、分页列表、保存、标签创建、主动另存与确认退出等命令。前端没有任意 SQL/Shell/文件路径写入权限。另存由 Rust 原生对话框选择新文件，JSON 保留结构化编辑内容；取消不显示成功，文件已存在则要求选择新文件名，不覆盖已有文件。该 JSON 不等于完整备份或已实现的自动导入格式。
