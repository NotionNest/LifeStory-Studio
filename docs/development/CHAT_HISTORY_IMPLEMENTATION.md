# 长聊天增量与连续滚动实施

2026-10-29，REQ-11/12/13 / TASK-11。依据用户本次实施授权及 2026-10-28 实测决策。

## 行为与验收

- 首开仅取尾部 100 条；前后读取使用 sequence/id 游标，SQL LIMIT，消息按升序展示。驻留最多 300 条，DOM 仅保留可见范围与少量预渲染行，不以切页按钮替代连续滚动。
- 增量轮询返回任务、最新元数据和游标后的消息。按 ID 与 sequence 去重；不变消息对象复用。来源、关联、预览和终态每次读取刷新，迟到或旧会话响应不可覆盖新窗口。
- 搜索由后端核对消息所属聊天并返回附近窗口；未加载不等于不存在。回到最新重新读尾页。查询失败明确展示错误，保留当前可读内容。
- 读取前后页、图片迟到、推理展开、窗口宽度改变保留可见消息锚点；末端跟随仅在原已贴底时发生。阅读历史时不得被生成拉回底部；搜索目标在虚拟行挂载后定位并聚焦。
- 显示窗口与生成选材完全分离，模型上下文、预览选材、已采用水位继续从完整授权历史读取。日记生成可用性按后端全历史判断。
- 不修改数据库已有消息，不迁移数据；不调用真实模型或读取私人资料。组件库不编写或运行测试。

## 实施顺序与影响范围

1. Rust ai/commands/lib：增加有界窗口与元数据/增量协议，复用同一事务中的 workspace 元数据读取，保留生成全历史路径。真实 SQLite 测试覆盖顺序、边界、归属、终态与完整上下文。
2. services/chats 与聊天会话：窗口协议、去重和上限、请求代次/顺序；更新初次加载、搜索、刷新与发送调用方及业务夹具。
3. ChatMessageList：使用 TanStack Virtual 的动态测量、稳定消息键与末端锚定，替换本页面原 MessageScroller 滚动所有权；复用消息内容、图片和推理控件。
4. 定向业务回归、Rust 存储测试、类型/构建、lint/架构/格式，合成浏览器连续滚动与高度变化验证。实际证据与未验证范围写入 STATUS.md。

不增加账号、同步、遥测、自动上传、模型截断或故障兜底。


## 当前实现与验证

上述四项已完成本轮代码与定向验证，双平台桌面验收仍待进行，实际次数、耗时和限制见 STATUS。TanStack Virtual 3.14.23 使用 anchorTo=end、稳定 ID、ResizeObserver 动态测量；已测量行在向上阅读时仍显式补偿视口上方尺寸变化。自动分页由原生 scroll 事件触发；统一通过 scrollToFn 记录程序化定位/尺寸校正的实际偏移，并在匹配的 scroll 事件中消费标记，不推断滚轮、键盘、触摸或指针输入。用户主动发送与成功回到最新通过会话版本触发末端定位，队列自动发送保留历史窗口；裁剪确已离开窗口的焦点消息时归焦聊天区域，其他焦点行保持挂载。前端业务夹具同步强制 page 协议，不增加缺失分页字段时的兼容降级。


2026-10-29 代码规范复审：删除全量读取分支及其重复 SQL，生产与 Rust 测试均使用 ai_chat_window；补齐构建命令清单与运行权限，旧自动生成权限文件删除，新文件由 Tauri 构建生成。ChatMessageList 仅装配和渲染，ChatMessageRow 展示消息/任务，useHistoryPaging 管理串行读取与失败重试，useChatScroll 负责虚拟测量、定位、焦点和滚动。贴底状态由会话维护，视图直接使用 loadWindow 与 setAtLatest，不暴露内部可变 ref 或保留一层透传包装。manualPending 改为可空的最新请求 ID，切换代次清空，只有对应请求完成才清除；已有迟到保护保留，补充两种重叠手动请求完成顺序的回归。


间距统一由虚拟列表 gap=24 管理，不再作为每行底部 padding 进入高度测量；起始留白 24、末端留白 48，保持原来总间距。真实键盘 Home 到顶后接前页的复验发现：行尾空隙计入行高时会漏补偿上方消息的 28px 增高；将间距与内容高度分开后，当前可见消息位置保持不变。此为原锚点验收范围内的修正，不新增输入类型判断。


## 2026-10-29 has_user_text 热路径优化

采用写入维护方案，不增加前端缓存、可选响应或 IPC 参数。schema 17 在 ai_conversations 增加 has_user_text，沿用原 json_tree/trim 条件一次回填旧消息；遵循既有迁移前备份与事务回滚。之后 AFTER INSERT 触发器只检查新增的用户消息，标记由 false 变 true；助手和仅图片/空文字消息不置位。触发器与消息同事务提交/回滚，重启保留结果。当前消息只追加，整聊天清理会级联删除元数据；未来若增加逐条消息修改/删除，需同步修订派生标记的维护规则。

所有窗口读取只按会话主键取标记，包括无新消息的轮询、较早历史页和搜索附近窗口，继续给出全历史语义。原 EXISTS 遇到首条有效文字会短路，不能概括为每次都解析全部消息；但无文字或首条文字较晚的聊天确有重复扫描成本，本次从读取路径彻底移除该扫描。

新增真实存储回归覆盖空/空格/助手消息、图片导入、首条文字、回滚、跨页与重启、旧版本回填/迁移备份/失败不改原数据；旧版本升级夹具同步去掉新版本字段和触发器，再重放原有迁移。运行范围与合成 SQL 工作量证据见 STATUS。
