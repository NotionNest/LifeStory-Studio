## 建议验证顺序

| 步骤 | 操作 | 应看到的结果 |
|---|---|---|
| 1 | 打开验证包，新建日记，填写合成标题/正文 | 进入独立编辑页，自动保存状态清楚 |
| 2 | 立即返回日记，再打开刚才记录 | 内容完整，首页筛选/月历和浏览位置保持 |
| 3 | 日记更多操作→查看历史→返回编辑 | 历史为独立页面；返回内容与滚动位置保持，编辑继续可用；普通往返不清空撤销历史 |
| 4 | 日记详情→设置→标题栏后退→前进 | 按访问顺序切换；回退后跳到另一个页面，前进按钮不可用 |
| 5 | 在非编辑控件聚焦时按 macOS ⌘[ / ⌘] | 与标题栏后退/前进一致；编辑框内不抢占文本操作 |
| 6 | 聊天输入合成草稿，不发送→设置→后退 | 聊天页重新显示时草稿仍在；不自动发送 |
| 7 | 设置→模型与提供商→API，修改配置名称但不保存→外观→返回 API | 表单修改仍在；无保存、连接测试或模型调用 |
| 8 | 日记详情→聊聊这篇日记→输入草稿→关闭侧边聊天→再次打开 | 正文不丢，侧边草稿保留；不自动发送 |
| 9 | 保留聊天或配置草稿，使用关闭按钮或 ⌘Q→返回继续 | 出现未发送/未保存提示，取消退出后输入保持 |
| 10 | 清理测试草稿并退出→重开验证包→打开合成日记 | 已保存标题、正文仍在，无重复新建记录 |

如需验证版本恢复：只对合成日记制造多个版本，再选择旧版本、确认恢复；应进入恢复后的编辑页，继续编辑可正常自动保存。普通历史浏览不自动恢复。

## 需要已有服务才能检查的流程

不要求为本轮新增真实密钥或付费调用。有合成聊天和生成结果的验证环境时，再检查：预览为独立页面，前进/后退恢复预览编辑；采用后明确打开日记；隐藏聊天或进入预览不自动投递排队消息；失败/停止后仍需明确继续。这些行为已有自动化保护，但尚未完成本轮实机验收。

## 反馈方式

记录“从哪个页面开始 → 点击/输入什么 → 实际结果”，附错误文字或截图即可。优先报告无法启动/白屏、内容丢失、错误发送、无法离开或退出、错误返回目标。未操作的步骤保持未验证，不据自动化结果标为人工验收通过。
