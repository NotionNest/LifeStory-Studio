# LIB-06 时间线、日历与组合查询实施

2026-10-21。关联 TASK-07、REQ-02/14，基线 develop 567bb15（LIB-05 PR #16 squash 合并）。分支 codex/library-search。用户授权实施 LIB-06，并在验收后授权整理提交、推送及创建指向 develop 的 PR；未授权合并或发布。

已确认：当前标题/正文/对话消息字面搜索；日期包含起止日；文字/对话/整理稿类型、标签全部/任一、有无图片组合；不检索旧历史、回收、图片内文字或独立 Vlog。时间线按记录日期、创建时间倒序及稳定 ID 排序；切换日历保留查询，选日替换日期范围。沿用当前编辑离开保护。

实施：
1. 后端有限查询接口返回分页结果、总数、当前月每日数量与可用标签；查询参数严格验证，短词/标点用字面匹配，三字符以上纯字母数字用 FTS5 trigram 缩小候选，再核对字面命中；不是索引错误后的兜底。消息仅取 JSON text 字段的正文，不检索身份元数据。大小写规则为英文 ASCII 忽略大小写，中文按原文。
2. schema 9 维护当前标题/正文搜索索引：触发器跟随记录写入/删除同步，重建旧索引；现有保存/导入/恢复改用同一索引维护，杜绝重复和旧词残留。
3. 列表搜索、按需组合筛选、时间线日期分组、月历计数与选日；查询变化立即使旧请求失效，失败有重试，分页不重复。筛选仅改变浏览集合，不卸载当前编辑；打开另一结果复用保存保护。
4. 持久化的对话与整理稿支持对应只读浏览，消息命中片段可见；本轮不生成模拟消息或提前实现 LIB-08 的 AI 创建/编辑能力。
5. 验证字面短词/标点/大小写、筛选交集/标签模式、分页和日历一致性、当前索引随保存/恢复/删除更新、历史/回收排除、迟到查询与未保存编辑保护；类型、Rust格式/测试/Clippy、生产构建和实际桌面操作。

不扩大到账号、云同步、媒体理解或全项目搜索。实际结果及平台限制写入 LIB06_VERIFICATION.md 和 STATUS.md。

日期口径沿用已确认规则：空日期可保存为待补充，但列表继续使用最后有效归档日期；列表日期、排序、日期筛选和日历计数统一使用该归档日期。月历数量应用关键词/类型/标签/图片条件，不应用日期范围，以便继续选其他日期；选日替换起止日期。
